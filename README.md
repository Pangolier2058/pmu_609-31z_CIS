## Описание проекта

Telegram-бот консультант, разработанный на языке Python с использованием библиотеки `pyTelegramBotAPI` (telebot). Бот представляет собой виртуального помощника для компании, предоставляющей финансовые услуги. Он помогает пользователям узнать о компании, ознакомиться со списком услуг и оставить заявку на консультацию.

## Функционал и особенности

*   **Интерактивное меню:** Удобная навигация с помощью `ReplyKeyboardMarkup` (кнопки «Услуги», «О нас», «Оставить заявку»).
*   **Раздел «О нас»:** Выводит информацию о компании и содержит `Inline`-кнопку со ссылкой на официальный сайт.
*   **Каталог услуг:** Выводит форматированный список предоставляемых услуг (отчетность, налоги, бюджетирование).
*   **Обработка заявок:** Реализован пошаговый сбор данных (выбор услуги -> ввод имени и телефона) с помощью `register_next_step_handler`.
*   **Административные уведомления:** Данные о новой заявке (услуга + контакты клиента) моментально отправляются администратору в Telegram.
*   **Обработка исключений:** Бот корректно реагирует на непредусмотренные сообщения, возвращая пользователя к главному меню.
